1. Choose a template

Every preset generates both floors. You can move furniture and export a version without affecting existing Hub bookings.

2. Select the floor

3. Editing mode

In edit mode, drag furniture on the drawing. Select a module for on-canvas rotation, changing the number of chairs, copying or deletion. In visitor preview, click actual chair symbols to try seat selection (demo only).

Add furniture

Add another 50 × 50 cm table when four guests need more space. Selecting an existing table lets you change 2 / 3 / 4 seats without recreating it.

4. Main circulation route

Drag the turquoise corridor to reposition it. Existing chairs stay where they are; any collisions are highlighted. Use “Reflow” to generate a new arrangement around the route.

5. Wall-mounted stage

The stage's back edge is always flush with the top wall (Y = 0). Adjust its width, depth, and horizontal position; it cannot float away from the wall.

6. Export your draft

The exported JSON contains template and geometry only, not guest records. No server connection or payments.
